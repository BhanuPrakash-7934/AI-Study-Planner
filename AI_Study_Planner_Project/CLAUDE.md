# AI Study Planner — Development Rules

## Stack
Next.js, TypeScript, React, Tailwind/CSS, Claude API, Zod, Vitest.

## Conventions
- Prefer Server Components unless interactivity requires Client Components.
- Keep AI provider credentials server-side.
- Validate all AI output before rendering.
- Use semantic HTML and accessible labels.
- Preserve user input on errors.
- Keep components small and testable.
- Use Conventional Commits.
